# Foto untuk empat surat

Taruh foto di folder ini:

- `ayah.jpg`
- `mama.jpg`
- `kakak.jpg`
- `eki.jpg`

Lalu isi `photo` di `CONFIG.wishes` pada `../../script.js`, misalnya:

```js
{ sender: 'Ayah', photo: 'assets/letters/ayah.jpg', /* properti lainnya tetap */ }
```

PNG/WebP juga bisa; sesuaikan ekstensi. Foto akan terlihat di atas isi surat masing-masing. Ucapan di `text` masih draft dan bisa diganti dengan pesan asli.
