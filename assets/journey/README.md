# Foto setiap milestone

Simpan 5 foto di folder ini, lalu isi `photo` pada `CONFIG.journey` di `../../script.js`:

| Milestone | Nama file | Nilai photo |
| --- | --- | --- |
| Dulu masih kecil banget | `01-kecil.jpeg` | `assets/journey/01-kecil.jpeg` |
| Ada aja ceritanya | `02-cerita.jpeg` | `assets/journey/02-cerita.jpeg` |
| Makin gede, makin jadi diri sendiri | `03-tumbuh.jpeg` | `assets/journey/03-tumbuh.jpeg` |
| Hari ini jatahnya Gegeh! | `04-sekarang.jpeg` | `assets/journey/04-sekarang.jpeg` |
| Masih banyak serunya nanti | `05-petualangan.jpeg` | `assets/journey/05-petualangan.jpeg` |

PNG dan WebP juga bisa; cocokkan nama dan ekstensi pada konfigurasi. Foto dapat diklik untuk diperbesar. Selama `photo` kosong, tampil bingkai bunga. Ganti judul/deskripsi milestone di item yang sama bila perlu.
